# AI HR Document Extractor

An AI-powered HR Document Extraction System that automates HR document processing using OCR, AI, and modern DevOps practices.

## 🚀 Features

- Document Upload API
- File Validation
- UUID-based File Storage
- OCR Processing (Coming Soon)
- AI Information Extraction (Coming Soon)
- PostgreSQL Integration (Coming Soon)
- Docker & Docker Compose
- AWS Deployment
- CI/CD with GitHub Actions & Jenkins
- Infrastructure as Code using Terraform
